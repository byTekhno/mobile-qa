# Mobile QA portfolio — тестирование на реальном устройстве (iPhone / Safari)

Учебный проект ручного мобильного тестирования. Первый этап — мобильный веб на реальном iPhone: [saucedemo.com](https://www.saucedemo.com) в Safari. Следующий этап — нативное Android-приложение Sauce Labs My Demo App на эмуляторе.

Цель репозитория — показать, как я адаптирую проверки под мобильную специфику (экран, касания, клавиатура, прерывания, сеть) и оформляю дефекты с указанием устройства и версии ОС.

**Объект тестирования (этап 1):** [https://www.saucedemo.com](https://www.saucedemo.com)  
**Тип:** веб-приложение в мобильном браузере  
**Уровень:** Junior QA, ручное функциональное тестирование

Десктопный прогон того же сайта: [saucedemo-qa](https://github.com/byTekhno/saucedemo-qa).
