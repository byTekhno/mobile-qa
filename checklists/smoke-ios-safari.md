## Итого

**Pass:** 36 / **Fail:** 0 / **Blocked:** 1 (п. 24) / **Не проверено:** 0

**Короткий вывод:** смоук 13/13 Pass; мобильная специфика 23 Pass / 1 Blocked. Новых дефектов на iPhone 11 / iOS 27.0.1 / Safari не найдено. Подтверждён известный дефект `visual_user` (п. 37). Наблюдения без дефектов: большие пустые блоки в карточках каталога (так же на десктопе при 375px, п. 3); Postal Code принимает любые символы (п. 26); в авиарежиме Finish завершается без ошибки, заказ нигде не сохраняется, т. к. сайт клиентский (п. 34). Blocked: п. 24, на клавиатуре нет кнопок «Далее» / «Готово».

## Как проходить

1. Использовать реальный iPhone, Safari, обновить страницу и открыть сайт заново перед каждым блоком.
2. Для каждого дефекта сразу делать скриншот или запись экрана (боковая кнопка + кнопка громкости; запись — из Пункта управления).
3. Баг оформлять по шаблону [bugs/_TEMPLATE.md](../bugs/_TEMPLATE.md), в чеклисте указывать его ID.
4. Если поведение совпадает с десктопом, это не мобильный баг: отметить «как на десктопе» (см. [saucedemo-qa](https://github.com/byTekhno/saucedemo-qa)).
